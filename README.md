# Predicting Canoe Performance 
These files contains mainly R-Code that runs on a specific dataset.

## About the Project
This R-Code is part of an analysis in which the aim was to evaluate whether machine learning models comprising anthropometric, physical fitness, and sport-specific performance data from young canoe sprint athletes can predict their senior performance level (SPL). 

## Additional
Empty folders (data, fig, tab, temp) has to be created by hand.
